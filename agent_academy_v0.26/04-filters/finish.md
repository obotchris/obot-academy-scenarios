# Congratulations!

You've completed the Agent Academy course on Obot v0.26 end to end.

## What You Learned Across the Course

- **Prerequisites** — logging in with your detected email and setting a password, becoming the Owner
- **Block 1: MCP Access** — adding MCP servers, exposing them through **Virtual MCPs (vMCPs)**, testing them with the **built-in MCP inspector**, connecting Claude Code via the gateway, and curating exactly which tools each vMCP exposes
- **Block 2: Auditing (Gateway)** — reviewing gateway tool calls (including inspector calls) in the audit log
- **Block 3: Auditing (Fleet & Local)** — enrolling the Obot Sentry client, inventorying your machine, automating scans with hooks, forwarding local MCP audit logs, and enforcing policy on the device
- **Block 4: Filters** — adding a source catalog and using gateway filters to redact and block sensitive data — and why testing filters matters

## Next Steps

- **Aggregate more servers into a vMCP** — combine several backing servers behind one endpoint and expose just the tools you need.
- **Use profiles** — grant vMCP access and specific tools to users and groups.
- **Add an auth provider** — Obot supports GitHub, Google, and enterprise providers alongside Local.
- **Add a model provider** — configure Anthropic, OpenAI, or another LLM for Obot's built-in chat and the MCP inspector.

For more details, visit the [Obot documentation](https://docs.obot.ai).
