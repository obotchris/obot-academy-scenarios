# Block 2: Auditing — Gateway Traffic

Every tool call routed through the Obot gateway — including calls made from the built-in MCP inspector — is recorded. In this block you'll open the audit log and see exactly what was called, by whom, and when, including the GitHub and PII tool calls you made in Block 1.

This is the first of two auditing blocks. Here you audit traffic that flows **through the gateway** via your vMCPs. In Block 3 you'll extend that visibility to **local** MCP activity on individual machines using the Obot Sentry client.
