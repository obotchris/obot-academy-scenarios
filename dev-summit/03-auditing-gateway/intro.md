# Block 3: Auditing — Gateway Traffic

Every tool call routed through the Obot gateway is recorded. In this block you'll open the audit log and see exactly what was called, by whom, and when — including the GitHub tool calls you made in Block 2.

This is the first of two auditing blocks. Here you audit traffic that flows **through the gateway**. In Block 4 you'll extend that visibility to **local** MCP activity on individual machines using the Obot Sentry client.
