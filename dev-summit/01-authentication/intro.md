# Block 1: Setting Up Authentication

In this block you'll configure **GitHub** as an authentication provider so users can sign in to Obot with their GitHub account, using the OAuth 2.0 flow. You'll then sign in as yourself and become the **Owner** of the instance.

This block assumes you've completed the **Prerequisites** section and are logged in with the bootstrap token, landing on the **Auth Providers** page.

By the end of this block you'll have a GitHub-authenticated Obot instance with yourself as the administrator.
