# Congratulations!

You've completed the Obot Dev Summit course end to end.

## What You Learned Across the Course

- **Prerequisites** — logging in to Obot with the bootstrap token
- **Block 1: Authentication** — setting up GitHub authentication and making yourself Owner
- **Block 2: MCP Access** — adding the GitHub MCP server and querying repositories from Claude Code via the Obot gateway
- **Block 3: Auditing (Gateway)** — reviewing gateway tool calls in the audit log
- **Block 4: Auditing (Fleet & Local)** — enrolling the Obot Sentry client, inventorying your machine, automating scans with hooks, and forwarding local MCP audit logs to Obot
- **Block 5: Filters** — adding a source catalog and using gateway filters to redact and block sensitive data — and why testing filters matters

## Next Steps

- **Add more MCP servers** — the catalog includes Slack, Jira, databases, and more.
- **Add Google auth** — Obot supports multiple auth providers side by side.
- **Add a model provider** — configure OpenAI, Anthropic, or another LLM for Obot's built-in chat.
- **Create an agent** — combine a model with multiple MCP tools into a custom agent.

For more details, visit the [Obot documentation](https://docs.obot.ai).
