# Block 2: Setting Up MCP Access

In this block you'll add the **GitHub** MCP server from Obot's catalog and connect Claude Code to it through the Obot gateway. You'll then call GitHub MCP tools directly from a Claude Code session to list your repositories.

This block assumes you've completed **Block 1** and have a GitHub-authenticated Obot instance with yourself as Owner.

Every call you make here is routed through the Obot gateway, where it is authenticated, authorised, and logged — which you'll review in Block 3.
